# ساخت APK نصب‌شدنی — GAMEVERSE ARCADE

این پروژه برای اجرای برنامه به‌صورت اپ اندرویدی مستقل آماده شده است. پس از نصب APK، آیکون **GAMEVERSE ARCADE** روی گوشی ظاهر می‌شود و برنامه از داخل WebView داخلی اندروید باز می‌شود؛ برای اجرای خود بازی‌ها مرورگر لازم نیست.

## ساخت APK در GitHub Actions (بدون نصب Android SDK روی رایانه)

پوشهٔ پروژه باید در یک مخزن GitHub قرار بگیرد. سپس:

1. مخزن را باز کن و به بخش **Actions** برو.
2. گردش‌کار **Build GAMEVERSE ARCADE APK** را از فهرست سمت چپ انتخاب کن.
3. **Run workflow** را بزن و اجرای ساخت را شروع کن.
4. وقتی اجرا با تیک سبز تمام شد، پایین صفحه در بخش **Artifacts** مورد **GAMEVERSE-ARCADE-APK** را دانلود کن.
5. فایل `app-debug.apk` را به گوشی انتقال بده، بازش کن و نصب را تأیید کن. اگر اندروید اجازه خواست، فقط برای برنامه‌ای که فایل را باز می‌کند اجازهٔ نصب را فعال کن؛ بعد از نصب می‌توانی آن را خاموش کنی.

فایل خروجی یک **APK آزمایشی امضاشده برای نصب و تست** است، نه نسخهٔ انتشار فروشگاهی.

## ساخت با Android Studio

پوشهٔ `android` را در Android Studio باز کن، اجازه بده Gradle و Android SDK با اینترنت دانلود و همگام‌سازی شوند، سپس از منوی **Build → Build APK(s)** استفاده کن. خروجی معمولاً اینجاست:

`android/app/build/outputs/apk/debug/app-debug.apk`

## ویژگی‌های آفلاین

- همهٔ محتوای بازی در `app/src/main/assets/index.html` بسته‌بندی شده است.
- برنامه مجوز `INTERNET` ندارد و بازی‌ها از فایل محلی اجرا می‌شوند.
- وضعیت‌های ذخیره‌شده با Local Storage در دستگاه نگه‌داری می‌شوند.
- شناسهٔ برنامه: `com.gameverse.arcade`

**محدودیت فعلی:** این محیط Android SDK یا Gradle نصب‌شده ندارد و دسترسی دانلود وابستگی‌های ساخت نیز در ترمینال فعال نیست؛ بنابراین APK نهایی را در همین محیط کامپایل نکرده‌ام. گردش‌کار بالا برای ساخت واقعی APK در محیط سازندهٔ اندروید اضافه شده است.
