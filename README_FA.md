# GAMEVERSE ARCADE — نسخهٔ نهایی ۱۰۰ بازی آفلاین

## محتویات
- `index.html`: نسخهٔ مستقل وب، راست‌چین و سازگار با گوشی.
- `android/`: پروژهٔ Android Studio با WebView آفلاین.
- `pwa/`: فایل‌های وب‌اپ قابل نصب.
- ۲۵ بازی اصلی GAMEVERSE به‌همراه ۷۵ بازی تازه؛ هر کدام کارت، هدف و روش بازی مشخص خود را دارند.

## اجرای فوری روی گوشی یا رایانه
فایل `index.html` را با مرورگر باز کن. برای بهترین پشتیبانی از ذخیره‌سازی و نصب، پوشهٔ `pwa` را روی یک وب‌سرور استاتیک HTTPS منتشر کن؛ بازی‌ها برای اجرا به اینترنت وابسته نیستند.

## تبدیل به اپ اندروید و گرفتن فایل APK مستقیم
پروژهٔ اندروید داخل پوشهٔ `android` قرار دارد. راهنمای فارسی در فایل `README_ANDROID_FA.md` و راه ساخت APK در `BUILD_APK_FA.md` است. گردش‌کار GitHub در `.github/workflows/build-apk.yml` محیط جاوا، Gradle و Android SDK را فراهم می‌کند و بعد از اجرای موفق، فایل `app-debug.apk` را به‌صورت مستقیم در Release می‌گذارد.

**محدودیت فعلی:** این بسته حاوی سورس آمادهٔ ساخت است، نه APK کامپایل‌شده. محیط فعلی Android SDK/Gradle ندارد و اجازهٔ دانلود ابزار ساخت را هم نمی‌دهد. بازی‌ها و دارایی‌های خود برنامه محلی‌اند و برای اجرا به سرور بیرونی نیاز ندارند.
